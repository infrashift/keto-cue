**keto-cue** is a fork of [Ory Keto](https://github.com/ory/keto), an open
source implementation of Google's Zanzibar authorization system. keto-cue
reads permission schemas in [CUE](https://cuelang.org). It does not read the
Ory Permission Language (OPL).

The CUE compiler writes the same namespace tree that the OPL parser wrote. The
check engine, the expand engine, the storage and the APIs do not change.

```cue
namespaces: {
	User: {}
	Folder: {
		relations: {
			parents: ["Folder"]
			viewers: ["User"]
		}
		permissions: view: or: ["viewers", "parents->view"]
	}
}
```

<Aside type="note" title="No release yet">
keto-cue has no binary release. Build it from source with Go. See
[Getting Started](./getting-started/).
</Aside>

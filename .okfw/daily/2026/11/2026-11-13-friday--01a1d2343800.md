## Notes

- A spike confirmed that an in-memory `build.Instance` resolves standard-library imports, rejects other imports and rejects mixed `package` clauses.
- `cue.Value.Source()` returns the whole field for a field value. The compiler takes `Field.Value` so that the caret points at the value.
- An empty disjunction against the base schema has base positions only. The compiler finds the user value by the error path. CUE writes list indexes as `types.0` in error paths.

## Phase 6: Short forms

- Started the CUE helper work that the user asked for. Filed [ISSUE-008](/issues/issue-008-short-forms-for-cue-rewrites-and-relations--01a1d4cf27e7.md) and decided [ADR-0007](/decisions/adr-0007-short-rewrite-forms-in-the-base-schema-compiled-in-go--01a1d4cf57cd.md).
- Rejected an importable CUE package. CUE has no functions, and hidden fields cannot carry parameters across packages. A constructor call is as long as the long form.
- The rewrites example has 391 characters in the short forms, 681 in the long form and 830 in OPL, without the header and the white space.
- A struct that fails a string-or-struct disjunction gives a summary error and the inner error, for example `field not allowed`. The compiler now drops the summary when an inner error exists.
- A comprehension can make the same error once per entry. The compiler now reports it once.
- CUE `+` on lists is not a good example for the user document. The document uses a list comprehension.
- A fuzz run of 90 seconds found no failure. The fuzz cache took about 1 GB, so I removed it. The root disk has 1.2 GB free.

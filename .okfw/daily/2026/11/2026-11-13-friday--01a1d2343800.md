## Notes

- The okfw MCP server loads after a Claude Code restart or an approval in `/mcp`.
- A spike confirmed that an in-memory `build.Instance` resolves standard-library imports, rejects other imports and rejects mixed `package` clauses.
- `cue.Value.Source()` returns the whole field for a field value. The compiler takes `Field.Value` so that the caret points at the value.
- An empty disjunction against the base schema has base positions only. The compiler finds the user value by the error path. CUE writes list indexes as `types.0` in error paths.
- Go fuzzing shows `0/sec` while it minimizes new inputs. A slow input is not the cause. Each corpus input took about 1 ms or less.
- Learned: CUE evaluation has no resource bound. Filed [ISSUE-007](/issues/issue-007-bound-cue-evaluation-on-the-syntax-check-listener--01a1d3adf8f1.md).
- The repo holds 62 OPL fixtures with about 126 class declarations. The equivalence test scans Go test files with `go/ast` for string literals that contain `implements Namespace`.
- `cue/format` prints a generated struct on one line when each field has the relative position `token.Blank`.

- Moved the fixture conversion from Phase 4 to Phase 3. The engine tests need CUE as soon as `schema.Parse` reads CUE.
- The root disk was full (195 MB free). Link steps and SQLite test databases failed with `no space left on device`. `go clean -cache -fuzzcache` freed 5 GB. The cache is safe to remove.

- Worked on Phase 4 in a git worktree, because a long test run compiled packages from the main tree.
- `internal/persistence/sql/migrations/migratest` timed out after 10 minutes on the full disk. keto-cue does not change that package.
